# Питч Дәптер AI

Презентация на 11 слайдов: проблема, решение, аналитика класса, отличия, рынок,
тарифы, себестоимость, план, риски и запрос к жюри. У каждого слайда есть заметки
докладчика (тег `<aside>` в конце файла).

Рабочий сервис, который можно попробовать: https://daptery-ai.vercel.app

Живая версия презентации для показа и выгрузки в PDF или PowerPoint:
https://claude.ai/artifact/NzZ9Zond4UdyngfXBcvCdv
(по умолчанию ссылка приватная: другие откроют её, только если владелец поделится ею в меню «Поделиться»).
