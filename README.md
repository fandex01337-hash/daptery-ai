# Дәптер AI

ИИ-помощник учителя: проверка рукописных работ школьников Казахстана за секунды.
Учитель фотографирует тетрадь, Google Gemini распознаёт почерк, решает задачу, находит
первую строку с ошибкой и предлагает балл. Итоговую оценку подтверждает учитель.

**Попробовать:** https://daptery-ai.vercel.app — нажмите «Сгенерировать пример с ошибкой»
или «Стопка из 5 работ», затем «Проверить». Если проверка не проходит из-за лимита ИИ,
включите «Демо-режим» в шапке.

Презентация для питча — в папке [pitch/](pitch/), бизнес-модель — в [BUSINESS.md](BUSINESS.md).

## Запуск локально

Нужен Node.js 18 или новее. Зависимостей нет: `npm install` не нужен.

1. Получите ключ на https://aistudio.google.com/apikey
2. Скопируйте `.env.example` в `.env` и вставьте ключ:
   ```
   GEMINI_API_KEY=ваш_ключ
   ```
3. Запустите:
   ```
   npm start
   ```
4. Откройте http://localhost:3000

Чтобы открыть приложение с телефона в той же Wi-Fi-сети, зайдите на `http://<IP-ноутбука>:3000`.
Камера через `<input capture>` работает и по http. Вставка из буфера в некоторых браузерах требует https или localhost.

## Деплой на Vercel

1. На https://vercel.com/new импортируйте репозиторий с GitHub (Framework preset: **Other**,
   остальные поля не трогайте).
2. В блоке **Environment Variables** добавьте `GEMINI_API_KEY` (и при желании `GEMINI_MODEL`,
   `GEMINI_THINKING`, `RATE_LIMIT_PER_HOUR`).
3. Deploy. Статика раздаётся из `public/` (это указано в `vercel.json`), а серверная функция
   `api/check.js` отвечает на `POST /api/check`. Дальше каждый `git push` в `main` обновляет сайт сам.

Сайт публичный, поэтому:

- с одного IP можно сделать не больше `RATE_LIMIT_PER_HOUR` проверок в час (по умолчанию 30,
  `0` — без ограничения). Счётчик живёт в памяти функции, это защита от случайного перерасхода,
  а не от атаки;
- настоящий потолок трат — бюджет и квоты в Google Cloud для проекта, к которому привязан ключ.
  Задайте их до того, как раздавать ссылку.

## Возможности для показа и пилота

- **Стопка работ.** Если выбрать или перетащить несколько фото, получится стопка: у каждой
  работы своё поле с именем и статус. Кнопка «Проверить N работ» проверяет их по очереди,
  аналитика класса обновляется после каждой. После двух ошибок подряд проверка останавливается,
  чтобы не ждать всю стопку при недоступном ИИ; кнопка продолжит с непроверенных.
- **Стопка из 5 работ.** Кнопка генерирует класс для показа: три работы с ошибкой в знаке,
  одна с вычислительной ошибкой, одна верная.
- **Демо-режим** (переключатель в шапке, по умолчанию выключен). Сгенерированные примеры
  разбираются по подготовленному ключу, без запроса к ИИ. Такие работы везде помечены «демо-разбор»,
  время ИИ для них не показывается. Загруженные фото в демо-режиме по-прежнему проверяет ИИ.
  Если ИИ ответил ошибкой на сгенерированном примере, рядом с «Повторить» появляется кнопка
  «Показать демо-разбор».
- **Скачать оценки (CSV).** Таблица проверенных работ для переноса в электронный журнал.
  Файл собирается в браузере, открывается в Excel без настройки.
- **Расход токенов.** Сервер пишет в лог число токенов каждой проверки: из него считается
  себестоимость (расчёт — в [BUSINESS.md](BUSINESS.md)).

Бизнес-модель, цены, риски и сценарий демонстрации описаны в [BUSINESS.md](BUSINESS.md).

## Скорость проверки

Время проверки почти целиком уходит на ответ Gemini. На него влияют три настройки в `.env`:

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `GEMINI_THINKING` | `low` | Сколько модель «думает» перед ответом: `minimal`, `low`, `medium`, `high` или `default` (как решит сама модель). `low` отвечает примерно втрое быстрее, чем `medium`. |
| `GEMINI_HEDGE_SECONDS` | `15` | Если ответа нет столько секунд, сервер параллельно отправляет запрос к следующей модели и берёт тот ответ, что придёт первым. `0` отключает. |
| `GEMINI_MODEL` | `gemini-3.6-flash` | Основная модель. |

Как сервер перебирает модели:

- Порядок: основная модель, затем запасные, в конце ещё раз основная. Одновременно идут
  не больше двух запросов, на одну работу уходит не больше четырёх.
- Ошибка 503 или 500 (модель перегружена): пробуем следующую модель.
- Ошибка 404 (модели нет): идём к следующей.
- Ошибка 429 (исчерпан лимит): идём к следующей, у каждой модели свой лимит. Если Google
  сообщил, когда лимит обновится, сервер до этого времени не обращается к этой модели.
- Неверный ключ: останавливаемся сразу.

Параллельный запрос тратит квоту запасной модели только тогда, когда основная зависла.

### Бесплатный тариф Gemini

На бесплатном тарифе действует суточный лимит на каждую модель. В ноябре 2026 года для
`gemini-3.6-flash` это 20 запросов в сутки: одного класса на это не хватит. Кроме того,
модели на бесплатном тарифе часто отвечают ошибкой 503 «high demand» или держат запрос
30–100 секунд. Для работы с классом нужен ключ с подключённой оплатой. Лимиты описаны на
https://aistudio.google.com/docs/rate-limits, текущий расход виден на https://ai.dev/rate-limit.

Когда лимит исчерпан или перегружены все модели сразу, ускорить проверку со стороны
приложения нельзя: учитель увидит сообщение с причиной и кнопку «Повторить».

## Устройство

```
public/            интерфейс (HTML + CSS + JS, без сборки)
  index.html       разметка: ввод, результат, аналитика класса
  app.js           загрузка и сжатие фото, проверка, результат, аналитика, sessionStorage
  sample.js        генератор тетрадного листа с ошибкой в знаке (canvas + шрифт Caveat)
  styles.css       светлая и тёмная тема, адаптив
lib/check.js       промпт, вызов Gemini, разбор и нормализация JSON
server.js          локальный сервер без зависимостей (статика + /api/check)
api/check.js       та же проверка как серверная функция Vercel
```

- **Ключ API** хранится только на сервере, в переменной окружения `GEMINI_API_KEY`. В браузер он не попадает.
- **Имя ученика** не отправляется в ИИ: в запросе есть только фото, предмет, класс, максимальный балл и критерии.
- **Проверенные работы** лежат в `sessionStorage` текущей вкладки и исчезают после её закрытия.
- **Фото** перед отправкой уменьшается до 1600 px по длинной стороне и сжимается в JPEG.
- **Модель**: по умолчанию `gemini-3.6-flash`. Запасные: `gemini-3.8-flash` и `gemini-flash-latest`.
  Другую основную модель можно задать через `GEMINI_MODEL`. Облегчённые модели (flash-lite)
  исключены намеренно: на живой проверке `gemini-3.5-flash-lite` пропустила ошибку в знаке.
- **Скорость**: описана в разделе ниже.
- **Ошибки** (нет сети, лимит запросов, ответ не в формате JSON, неверный ключ) показываются
  по-русски, рядом есть кнопка «Повторить».
